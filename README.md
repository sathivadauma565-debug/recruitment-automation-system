# Recruitment Automation System 🚀

## Description
This project automatically screens resumes using skill matching.

## Features
- Resume Upload
- Skill Extraction
- Score Calculation
- Auto Selection / Rejection
- Resume Download

## Tech Stack
- Python
- Django
- HTML, CSS

## How it Works
1. Admin adds job
2. User uploads resume
3. Skills are extracted
4. Score is calculated
5. Candidate is selected or rejected
